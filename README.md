# ScholarPulse UK

CS5079 Applied AI final submission. Md Shamim Mia, Student ID 52536283, University of Aberdeen.

ScholarPulse UK is a local research and funding command deck for every UK student stage: undergraduate dissertation, MSc taught project, PhD applicant, current PhD, international student, and student founder. The display name lives in `src/fundmatch/brand.py`. The import package and the command stay `fundmatch`, so existing imports do not change.

Paste a title and an abstract. The app returns a calibrated shortlist of UKRI councils, a conformal set tied to the published test profile, similar funded projects, a band of past awards, five working titles, a readiness radar, an upgrade coach, reviewer questions, and the UK organisations nearest that topic. The classifier is the exported CS5079 model: 200,000 sublinear word and bigram features, class-weighted logistic regression, temperature **1.1314305006097425**. Held-out macro-F1 **0.8615**, accuracy **0.8693**, top-3 **0.9916**, ECE **0.0336 → 0.0180**. The index is all **113,233** projects collected on 23 November 2026. The table has organisations, not people. Pasted abstracts are not stored.

This is not official UKRI funding advice. UKRI does not endorse it.

**Live app:** https://scholarpulse-uk.streamlit.app/. The free host sleeps after 12 hours without visits. If you see the sleeping page, click "Yes, get this app back up!" and wait about a minute.

**Requirements audit:** [`docs/REQUIREMENTS_AUDIT.md`](docs/REQUIREMENTS_AUDIT.md) checks every product requirement (FR-1 to FR-27, NFR-1 to NFR-14, the MoSCoW features and the marking map) against this code. It gives a status, the evidence, and a map from each requirement to its file or notebook section.

**How the model was trained:** [`training/`](training/README.md) holds the collection and join scripts, the executed training notebook (outputs kept), the result tables, the figures and the group report. No Kaggle data, GtR bulk export or GtR-Extended data was used. All data was fetched by our own code from the public GtR API.

## Quick start

Python 3.11 or 3.12. On Windows, Python 3.14 has no ready-made numpy 2.2.6 wheel, so create the virtual environment with Python 3.11 (`py -3.11 -m venv .venv`).

```bash
pip install -r requirements.txt
pip install -e .
fundmatch ui
fundmatch serve --port 8741
fundmatch analyze --demo epsrc-quantum --student --cpih
fundmatch coach --demo epsrc-quantum --persona masters
fundmatch redteam --demo epsrc-quantum --persona phd
fundmatch hubs --demo epsrc-quantum
fundmatch dossier --demo epsrc-quantum --persona undergrad --output scholarpulse_research_dossier.md
fundmatch topics --interest "school exclusion and later earnings" --persona undergrad
fundmatch trends --interest "wheat drought genetics"
fundmatch fuse --a "music" --b "machine learning"
fundmatch score --demo epsrc-robotics --persona masters
pytest -q
jupyter nbconvert --to notebook --execute --inplace notebooks/01_fundmatch_pipeline_and_evaluation.ipynb
```

`./start.sh` and `docker compose up --build` start Streamlit on port 8765.

## V5 Neon Edition: Idea Studio (28 November 2026)

V5 restyles the app as a dark, glassy "command deck" (CSS only, in `src/fundmatch/assets/neon.css`: neon accents, animated hero border that switches off under `prefers-reduced-motion`, visible keyboard focus, and a mobile layout where the demo chips wrap). It adds the features below. All logic is in `src/fundmatch/insights.py` and is tested in `tests/test_v5_insights.py`. Every number comes from the deployed model, the held-out test profile in `artifacts/model_info.json` or the GtR rows; nothing is generated by a language model and no paid API is called.

- **Four-step guide** at the top, which can be hidden.
- **Mission brief** under the Analyze button: a gauge of the top calibrated probability, the held-out test accuracy for that probability band (for example 94.3% for 0.8–1.0), the lead over the runner-up, the 90%/95% shortlists, the novelty band, the typical nearby award, and one-click links to the live UKRI Funding Finder for each shortlisted council.
- **Idea Studio** (new first tab, the original eight tabs are unchanged):
  - *Explain*: a bar chart of the words that push the chosen council up or down (TF-IDF weight × coefficient ÷ temperature), and the accuracy-by-confidence chart with your band highlighted.
  - *Draft checklist*: ten rule-based checks (aim, gap, method, success measure, beneficiaries, outputs, scope boundary, length, sentence length, specific vocabulary), each showing the words that triggered it. It is a writing aid, not a prediction of funding success.
  - *Vocabulary*: terms used in the 50 nearest funded titles that the draft does not use, with their counts and the model's weight, plus a what-if simulation for terms the writer confirms are true.
  - *Precedents*: the 50 nearest funded projects, filtered by council, start year and award, on a year × award chart, with CSV download.
  - *Idea vs idea*: two ideas side by side, with both probability profiles, semantic closeness in the abstract map, and how many nearest projects they share.
  - *Export*: a PDF brief (fpdf2, imported only when the button is pressed), plus Markdown, CSV and JSON.

Memory and speed, measured on a Linux test machine (Python 3.13) on 28 November 2026: Streamlit server peak 712 MB for V4 and 707–715 MB for V5.0. The V5.1 audit fix (the query projection no longer copies a 100 MB matrix on the first search; results are bit-identical) lowers it to 613–616 MB after opening every studio tool and building a PDF; a warm rerun takes 0.57–0.61 s.

## V5.2: Gap finder and 3D idea map (28 November 2026)

Two more tools in the Idea Studio, both in `src/fundmatch/gaps.py` and tested in `tests/test_v52_gaps.py`. They use only the real GtR rows and the SVD vectors the app already loads. There is no new model and no new data.

- **Gap finder.** The 400 funded projects nearest your idea are fetched. Those that sit far from it in the SVD map (closeness below 0.75 of the neighbourhood median) are dropped, and the rest are grouped into 3 to 10 sub-topics with a small deterministic k-means written in NumPy. Each sub-topic shows its key title words, project count, total and median priced award, how many projects are priced, its trend (the share of its projects that started in 2022–2025 against 2018–2021, compared with the same share for the whole neighbourhood: growing, flat or shrinking by at least 8 points), the most common council among its projects, and three example projects with GtR links. A sub-topic is **under-explored** when it is at least 15% below the average sub-topic on both project count and total award and is among the thinnest on count, total and median award (at most three are flagged). It is **crowded** when it has at least 20% more projects than average (at most two are flagged). A bubble chart plots crowdedness against growth. Sub-topics with fewer than three priced projects are marked, because their £0 is unpriced records, not proof of low funding.
- **3D idea map.** The 300 nearest funded projects are placed in 3D by PCA fitted on those neighbours only, with your idea projected onto the same axes as a glowing marker. Points are coloured by council (or by gap sub-topic), sized by award on a log scale, and show the title, year, award and GtR link on hover. The axes are labelled "Semantic axis 1/2/3" with the share of the neighbours' spread each explains, and the page says that a 3D projection distorts distances.

For the example idea ("Learning control for superconducting quantum processors"), 273 of the 400 nearest projects are kept. The Gap finder flags three under-explored sub-topics (qubit tuning and machine learning, with 24 projects that are all unpriced studentships; superconducting amplifiers and sensors, 21 projects, £4.71m, shrinking; optical and spin control dynamics, 28 projects, £6.36m, flat) and two crowded ones (hybrid quantum interfaces and networks, 55 projects, growing; trapped-ion computing, 45 projects, shrinking).

**What it does not mean.** Low funding is not the same as opportunity: a thin area can reflect low priority, work filed under other words, or gaps in the data. GtR shows awards made in the past, not open calls. Unpriced studentships appear as £0, so they add projects but no money. Sub-topics are a rough clustering and amounts are nominal pounds. The page states all of this above the results.

Cost: about 0.08 s per idea on the Linux test machine (median over 20 runs; 0.27 s on the PC), no extra files, and no change to the Streamlit server's memory peak (613–618 MB after opening every studio tool including both new ones and building a PDF; V5.1 was 614–617 MB).

## What a student can do

- Read eight council probabilities, a 90% and 95% set, and live Funding Finder links. A single council is shown at 90% only when the probability is at least 0.80, because that test bin was 94.3% accurate. Otherwise the set is the top three (test top-3 accuracy 0.9916).
- See how close the text sits to the 113,233-project map, and open the nearest funded projects by organisation.
- Generate five working titles from words in those real titles, each with a council, a calibrated percentage, and a novelty band.
- Ask the upgrade coach for 6–8 terms that appear in funded neighbours and are missing from the draft, then read a labelled before/after simulation. The after-score is not a new scientific claim.
- Read five viva questions and a five-dimension feasibility matrix.
- See the ten organisations with the most awards among the 60 nearest projects, in October 2026 pounds.
- Download one Markdown dossier: idea, radar, councils, titles, hubs, coach, email template, red-team, funding wave, and the OGL v3.0 footer.
